# Token 成本

守护灵每做一步动作就是一次 LLM 往返,而每次往返都要把**系统提示词 + 全部工具 schema**
原样重发一遍。所以固定开销不是付一次,是 **× 任务步数**。

免费的对手(如「工具人」那类硬编码 FSM)每步花 0 元。我们要卖钱,就必须知道钱花在哪。

## 怎么量

```bash
dotnet run --project tools/ToolBench -p:SurvivalcraftDir=$HOME/sc-libs/ -- --budget
# 要真数不要估算:导出真实 payload,POST 一次,读回 prompt_tokens
dotnet run --project tools/ToolBench -- --budget --dump /tmp/payload.json
```

运行时每次请求也会记一行真实用量(`LlmClient.LogUsage`):

```
[Genius] llm usage: in 12367, out 17, cached 4608
```

## 2026-08-11 实测(数字是 POST 回来的,不是估的)

| | tokens |
|---|---|
| **中转站基线** | **4,395** |
| 系统提示词(4,500 字中文) | ~5,983 |
| 工具 schema(30 个,12,171 字符) | ~1,990 |
| **每步实际计费(不含历史)** | **~12,367** |

三件事和我一开始说的**不一样**,都是量出来才发现的:

### 1. 每次请求先白付 4,395 token,与我们写什么无关

`system="hi"` + `user="1"` 实测:gpt-5.4-mini 4,394、gpt-5.6-sol 4,396、gpt-5.4 4,396。
三个模型一致 ⇒ 是**网关/上游注入的**,不是我们的内容。

**我们改不掉它。唯一能减少它的办法是少走几步。** 40 步的任务光这一项就是 17.6 万 token。

### 2. 大头是系统提示词,不是工具 schema

我原先估工具 3,878 / 提示词 2,442,据此去瘦身工具描述——**方向反了**。
真实是提示词 5,983、工具 1,990,**提示词是工具的 3 倍**。

### 3. 中文比英文贵约 4 倍(在这个中转站上)

拟合出来的系数:

| | tok/char | 拟合方式 |
|---|---|---|
| 中文 | **1.90** | +4,725 字 → 13,393(减基线) |
| 英文散文 | **0.44** | +4,500 字符 → 6,393(减基线) |
| JSON | **0.164** | 工具块 12,171 字符 → 1,990 |

所以之前写在这里的「把工具描述改成中文能省 token」是**错的**,在这个中转站上会贵约 4 倍。
真要省,该动的是**中文系统提示词**。

(第一版估算器用 CJK 0.75 / 其余 0.30,同时在两个方向上错:中文少算 2.5 倍、
工具 JSON 多算 2.7 倍,正好把优化指向了错的那一块。系数是中转站特定的,换后端要重新拟合。)

### 已做的两处改动,按真实尺子重算

| | 改前 | 改后 |
|---|---|---|
| tool schemas(缩进 → 紧凑) | ~3,047 | **~1,996** |

`Formatting.None` 省的是 ~1,050 tok/步(不是我先前按错系数算的 1,850),仍然是一行代码的白拿。

## Prompt caching

`GeniusSettings.PromptCache`:`auto`(默认)/ `on` / `off`。

`auto` 只对 Claude 系模型加 `cache_control` 标记——OpenAI 自己会缓存、不需要标记,而未知
网关可能直接拒收带标记的请求。打两个断点(Anthropic 对工具循环的推荐姿势):

- 系统提示词后一个(工具 schema 在前缀里,一起被缓存)
- 最新一条消息上一个(这样下一步能读到上一步写进去的全部历史)

网关若不认 `cache_control`,客户端会**当场去掉标记重发一次**并记住,不会让守护灵哑掉
(`LlmClient` 的 400/422 + "cache" 分支)。

缓存读价通常是输入价的 1/10:5,950 tok/步的固定前缀命中后按 ~595 tok 计费。

## 还没做的两件

- **按情境只挂载工具子集**——真实收益比我先前吹的小得多:工具总共才 ~1,990 tok/步,砍一半
  只省 ~1,000。模型看不见的工具就不会调用,ToolBench 的采样噪声压不住这种行为改动。
  **性价比已经不高,先放着。**
- **压缩中文系统提示词**——它才是最大的一块(~5,983 tok/步),而且中文单价是英文的 4 倍。
  但提示词的每一行几乎都是某次实测翻车换来的,删哪一行都要能说清代价——同样卡在验证手段上。

## 真正的大头仍是步数

上面全部是**每步**的钱;总账 = 每步 × 步数。playtest 10 里盖一间房用了
**107 次 `place_block`**——换成一次 `build_shelter` 就是百倍。

量出中转站基线之后这条更硬了:**每步有 4,395 token 是我们一个字都改不动的**,
占每步计费的三分之一。提示词再怎么瘦身都碰不到它,只有少走一步才能省下一整份。

> 凡是有唯一正确答案的动作,就不该经过大模型:一次经过就是一次钱。
